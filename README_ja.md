# Sonic Topography

[最新リリースをダウンロード](https://github.com/yin-yizhen/sonic-topography/releases/tag/1.1.1) | [Windows版](https://github.com/yin-yizhen/sonic-topography/releases/download/1.1.1/SonicTopography-1.1.1-Setup.exe) | [macOS (Appleシリコン版)](https://github.com/yin-yizhen/sonic-topography/releases/download/1.1.1/SonicTopography-1.1.1-mac-arm64.dmg) | [macOS (Intelプロセッサ版)](https://github.com/yin-yizhen/sonic-topography/releases/download/1.1.1/SonicTopography-1.1.1-mac-x64.dmg)

Sonic Topographyは、デスクトップ向けの音楽プレイヤー兼3D音楽ビジュアライザアプリケーションです。音楽の低音域、中音域、高音域を、起伏し、発光し、点滅する立体的な地形へと変換し、音楽を聴く体験をまるで呼吸しているかのような「音の地図」へと変貌させます。

## 主な機能

- デスクトップアプリケーション：Electronベースで構築されており、起動後は独立したウィンドウとして動作するため、ブラウザのタブを常に開いておく必要がありません。
- 3Dミュージックトポグラフィー：音楽の周波数帯域が、地面のシリンダー、光の演出、波紋、流星、そして歌詞の表示をリアルタイムで駆動します。
- ローカル音楽再生：ローカルのオーディオファイルをアップロードして再生可能で、`.lrc`形式の歌詞ファイルにも対応しています。
- デモ機能内蔵：初回起動時に音楽を用意していなくても、すぐにビジュアライズ効果を確認できます。
- 網易雲音楽（NetEase Cloud Music）：デスクトップ上で公式ログインウィンドウを開き、QRコードをスキャンして本機のCookieを読み込むことで、検索、プレイリスト、デイリーおすすめ（デイリーミックス）、再生機能を利用できます。
- QQ音楽（QQ Music）：デスクトップ上で公式ログインウィンドウを開き、QRコードをスキャンしてQQ音楽のCookieを読み込むことで、検索、再生、歌詞表示機能を利用できます。
- ローカルプレイリスト：お気に入りの楽曲をローカルのプレイリストに保存できます。
- 直感的なグラフィックイコライザー（地面EQ）：8つの周波数フェーダーを使用して、それぞれの音域が地形に与える影響を個別にコントロールできます。
- 時計表示とポモドーロタイマー：作業や休息、集中したいときに最適な表示モードへと視覚エフェクトを切り替えることができます。
- プリセットの移行：プレイリスト、エフェクト、地面EQ、カスタムテーマ、ブラウザ設定のインポートおよびエクスポートに対応しています。

## クイックスタート

アプリケーションを利用するだけの場合：

1. お使いのOS（Windows / macOS）に対応したインストーラーをダウンロードしてインストールします。
2. `Sonic Topography` を起動します。
3. 左上の `AJIN.` をクリックしてサイドバーを開きます。
4. まずは `サンプル`（示例）をクリックして内蔵デモを再生し、映像と音声が正常に動作することを確認してください。
5. 自分の音楽を再生したい場合は、`アップロード`（上传）をクリックしてローカルのオーディオファイルを選択します。
6. 網易雲音楽（NetEase Cloud Music）またはQQ音楽（QQ Music）を利用したい場合は、`設定 -> アカウントログイン`（设置 -> 账号登录）に進み、画面の指示に従って公式ウィンドウを開き、QRコードをスキャンしてログインしてください。

## 各画面へのアクセス

左上の `AJIN.` をクリックするとサイドバーを開くことができます。

- `ビジュアライズ`（可视化）：パネルを閉じ、3Dミュージックトポグラフィーの画面に戻ります。
- `設定`（设置）：ビジュアライズ、地面EQ、テーマ、アカウントログイン、表示関連の設定を開きます。
- `検索`（搜索）：網易雲音楽（NetEase Cloud Music）およびQQ音楽（QQ Music）から楽曲を検索します。
- `網易雲音楽`（网易云）：有効な網易雲音楽のCookieが保存されると表示され、お気に入り、プレイリスト、デイリーおすすめにアクセスできます。
- `プレイリスト`（歌单）：ローカルに保存されたプレイリストを開きます。
- `サンプル`（示例）：内蔵デモを再生します。
- `アップロード`（上传）：ローカルのオーディオファイルまたは `.lrc` 歌詞ファイルを選択します。
- `全画面表示`（全屏）：全画面モードの切り替え（進入/解除）を行います。

## 地面EQ

地面EQは、音楽の各周波数帯域が3D地形にどのように影響するかをコントロールするためのものです。これは単に音質を変えるだけの一般的なイコライザーではなく、視覚効果に特化した「地面エフェクト用ミキサー」です。

![直感的なカスタム地面EQ](./public/screenshots/ground-eq.png)

各フェーダーは、それぞれ異なる視覚的なキャラクターに対応しています：

- `SUB BASS / 中心持ち上げ`：重低音を中央に集中させ、地面の中心部を押し上げます。
- `BASS / 低音の重量感`：低音域がもたらす重厚感をコントロールします。
- `LOW MID / スローウェーブ`：地形に、より緩やかな波動を生み出します。
- `MID / ディレクショナルフロー`：中音域がもたらす方向性のある起伏をコントロールします。
- `HIGH MID / ピーク（鋭さ）`：リズムや強調したい部分に、鋭い突起を作りやすくします。
- `PRESENCE / フラッシュトリガー`：局所的なフラッシュ（発光）やハイライトをコントロールします。
- `BRILLIANCE / エッジスパークル`：細やかで軽快な、エッジ部分のきらめきを強調します。
- `AIR / エアパーティクル`：より高音域で、空気のような軽い粒子感をコントロールします。

上部にある `起伏速度`（起伏速度）は、地形が隆起・沈降する速度に影響します。数値を高くするほど地面の動きが俊敏になり、低くするほど視覚効果が滑らかで柔らかな表現になります。

## 時計表示とポモドーロタイマー

Sonic Topographyは、デスクトップの作業用（集中用）バックグラウンドとしても活用できます。時計表示を有効にすると、3D地形の上に大きなデジタル時計がオーバーレイ表示されます。ポモドーロタイマーと組み合わせることで、仕事、勉強、読書、または休憩の時間を管理するタイマーとして機能します。

![時計表示とポモドーロタイマー](./public/screenshots/focus-clock.png)

おすすめの使い方：

1. 集中に適した音楽や環境音（BGM）を再生します。
2. 時計表示を有効にします。
3. 自分のペースに合わせてポモドーロタイマーを開始します。
4. 全画面表示（フルスクリーン）に切り替え、インテリアに馴染む軽量な作業用デスクトップとして活用します。

## アカウントログイン

`設定 -> アカウントログイン`（设置 -> 账号登录）を開き、`網易雲音楽`（NetEase Cloud Music）または `QQ音楽`（QQ Music）を選択します。

Electronデスクトップ版では、`公式ウィンドウを開いてQRスキャン`（打开官方窗口扫码）をクリックすると、公式のウェブログイン画面がポップアップ表示されます。ログインに成功すると、アプリケーションがそのウィンドウからCookieを自動的に読み込み、ローカルのプロキシサービスに同期します。

通常のブラウザ（開発環境など）ではQRコードログインは利用できません。手動でのCookie入力ボックスは、ダウングレード時のデバッグ用としてのみ用意されています。

Cookieは重要なログイン資格情報（機密データ）であり、ローカルPC内にのみ保存されます。自身のCookieをエクスポートしたり、アップロードや共有をしたりしないでください。

## プリセットのインポート・エクスポート

設定画面から、プリセットのインポートおよびエクスポートが可能です。別のPCに自身の視聴環境や視覚的な設定を移行したい場合に最適です。

移行可能な項目：

- プレイリスト
- パルスエフェクト（脈動効果）
- 流星エフェクト
- 地面EQ
- カスタムテーマ
- ブラウザ設定

エクスポート時には、Cookieを含めるかどうかを選択できます。セキュリティーの観点から、ご自身でリスクを完全に理解しており、かつ自身のデバイス間でのみ移行する場合を除き、通常はCookieを含めずにエクスポートすることをおすすめします。

## ローカルデータ

- テーマ、エフェクト、地面EQ、アカウントのCookie、およびほとんどの設定はローカルPCに保存されます。
- 開発用ソースコードから実行している場合、ローカルのプレイリストは `/api/playlists` を経由して `data/playlists.json` に保存されます。
- ビルド（パッケージング）済みのデスクトップアプリケーションは、ローカルサービスのデータをElectronのユーザーデータディレクトリ（UserData）に保存します。
- アップロードされた実際のオーディオファイルは、プリセットファイルに書き込まれることはなく、インストーラーに同梱（パッケージング）されることもありません。

## 開発と実行

依存関係のインストール：

```powershell
npm install
```

日常的な開発では、Electronモードの使用を推奨します：

```powershell
npm run dev:electron
```

このコマンドは、Viteの開発サーバー（dev server）を起動したあと、Electronウィンドウを開きます。`src/`、CSS、Reactコンポーネント、設定画面のUIを変更した際は、基本的にホットリロード（HMR）が適用されます。

ブラウザ上だけでUIの調整を行いたい場合：

```powershell
npm run dev
```

ブラウザのアクセスURL：

```text
http://127.0.0.1:3000
```

以下の内容を変更した場合は、通常Electronの再起動が必要です：

- `desktop/main.js`
- `desktop/preload.cjs`
- Electronのビルド設定、ウィンドウの挙動、IPCログインブリッジ（橋渡し）
- ローカルサービスおよびプロキシ関連のコード

## ビルド（パッケージング）

リリース前に実行します：

```powershell
npm run build:electron
```

生成されたWindows用インストーラーの出力先：

```text
release/
```

インストーラーを生成せず、実行可能ディレクトリのみを生成したい場合：

```powershell
npm run build:electron:dir
```

## 注意事項

- 網易雲音楽（NetEase Cloud Music）およびQQ音楽の再生結果は、著作権、有料会員、地域、アカウントの状態による影響を受ける場合があります。
- 検索結果には、現在の匿名状態または現在のCookie権限でアクセス可能なコンテンツのみが表示されます。
- `dist/`、`release/`、ローカルの `data/`、アップデートのダウンロードディレクトリ、またはアカウントのCookieをGitにコミットしないでください。
- 音楽の検索はできるが再生できない場合は、アカウントの状態、楽曲の著作権、および現在の音質（ビットレート）が利用可能かどうかを優先的に確認してください。
